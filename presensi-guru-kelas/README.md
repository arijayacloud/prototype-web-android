# RuangKelas — Presensi Guru

Prototype front-end untuk alur yang terkonfirmasi di percakapan: perwakilan setiap kelas mengisi status guru pada delapan jam pelajaran; kepala sekolah melihat rekap kelas berbentuk matriks berwarna; administrator mengelola kelas dan wali kelas; kurikulum meninjau status yang perlu perhatian.

## Yang bisa dicoba

- Ringkasan 30 kelas dan status setiap jam pelajaran.
- Filter kelas dan tingkat; pilih sel untuk mengubah status demonstrasi.
- Form input contoh untuk perwakilan kelas.
- Rekap matriks dan unduhan CSV dari data contoh.
- Data master contoh untuk melihat dan mengubah wali kelas atau menambah kelas.
- Pilihan peran untuk memperlihatkan variasi tampilan.

Data demonstrasi disimpan di `localStorage` browser. Akun multiuser, sinkronisasi antarperangkat, database online, notifikasi, dan koneksi ke server belum tersedia. Nama wali kelas dan angka pada dashboard adalah data fiktif. Ini prototype untuk ditinjau, bukan sistem sekolah yang sudah beroperasi.
