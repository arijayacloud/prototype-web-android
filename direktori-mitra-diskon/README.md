# TemuDiskon — prototype direktori mitra

Prototype front-end berdasarkan kebutuhan direktori tempat usaha/promo per kota dan kategori (cafe, kecantikan, kesehatan) dengan halaman detail mitra dan panel admin sederhana.

## Alur demo

- Pilih kota dan kategori, cari mitra/promo
- Lihat detail tempat, promo, syarat, alamat, dan kontak contoh
- Simulasi tombol peta/kontak
- Beralih ke panel admin untuk menambah, mengubah, menghapus mitra dan menambahkan kota

## Batasan

Nama, alamat, promo, rating, dan kontak adalah data placeholder. Tidak ada login, database/server, unggah gambar yang tersimpan, sinkronisasi, review aktif, tautan kontak, atau integrasi Google Maps. Perubahan CRUD/kota hanya berada sementara di memori halaman dan hilang saat dimuat ulang. Ini bukan aplikasi produksi.
