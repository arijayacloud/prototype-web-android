# Ruang PPDB — prototipe penerimaan siswa

Demo front-end untuk kebutuhan WhatsApp otomatis yang memberi informasi sekolah/jurusan dan membantu calon siswa mengirim pendaftaran beserta berkas.

## Alur yang dicontohkan

- Calon siswa melihat simulasi percakapan WhatsApp dan memilih topik informasi sekolah/jurusan, cara daftar, atau berkas.
- Formulir menerima data contoh, pilihan program keahlian, dan berkas.
- Admin melihat ringkasan pendaftar serta status dokumen.
- Rekap pendaftar dapat diunduh sebagai CSV contoh.

Ini hanya rancangan tampilan dan alur. Chat tidak tersambung ke WhatsApp/bot aktif, form tidak mengirim ke server, unggahan tidak disimpan, dan rekap tidak tersambung ke Excel, database, autentikasi, atau notifikasi sungguhan. Nama sekolah, jurusan, isi informasi, persyaratan, dan data pada dashboard adalah placeholder yang perlu diganti dengan informasi resmi setelah dikonfirmasi.
