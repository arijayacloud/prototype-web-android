# Xinda Pack Commerce

Prototipe web untuk alur katalog dan pemesanan kemasan yang diminta pada form.

## Cakupan interaksi

- Katalog dengan pencarian dan filter kategori.
- Keranjang, pengaturan jumlah, ringkasan checkout, dan input data pengiriman.
- Opsi pembayaran contoh (transfer, QRIS, e-wallet), kupon, dan pilihan bukti transfer.
- Jalur kontak Admin WhatsApp dan jadwal kebutuhan/pengadaan.
- Panel admin berisi ringkasan penjualan, grafik mingguan, daftar order, simulasi konfirmasi, stok, dan unduhan CSV.

Nama, produk, harga, transaksi, grafik, stok, dan status pada halaman adalah data contoh yang dapat diganti setelah informasi katalog resmi diterima. Ini prototipe front-end: interaksi berlangsung di browser dan belum menyimpan order atau file ke server maupun memproses pembayaran/pengiriman sungguhan.

## Membuka

Buka `index.html` di browser atau kunjungi GitHub Pages setelah deploy selesai.
