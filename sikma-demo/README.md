# SIKMA — prototype front-end

Demo ini menggambarkan alur konsultasi OPD: tiket, telaah auditor, permintaan data, validasi Irban, dan eskalasi kasus tertentu ke Inspektur. Halaman juga memperlihatkan pengingat 1×24 jam, tenggat tahap jawaban, dashboard monitoring/rating, mockup SIKMA-Assist, serta contoh notifikasi WhatsApp.

Semua organisasi, akun, tiket, metrik, komentar, dan cap waktu dalam demo adalah data contoh. Tombol hanya mengubah tampilan sementara di browser. Demo belum memiliki login multiuser, database, penyimpanan atau unggah dokumen, gateway WhatsApp, sinkronisasi, perhitungan SLA aktual, atau ekspor laporan produksi. SIKMA-Assist ditampilkan sebagai mockup tahap berikutnya.

## Membuka demo

Buka index.html di browser. Tidak memerlukan paket atau layanan pihak ketiga.
