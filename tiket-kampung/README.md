# TemuTiket — prototype platform tiket kampung

Demo UI untuk kebutuhan sistem ticketing multi-penyewa/event: Admin Utama, akun kampung/penyewa, event dengan harga dan kuota, transaksi cash di loket, ilustrasi tiket/QR, simulasi validasi satu kali, dashboard penjualan, dan cetak struk berformat 58 mm.

## Batasan demo

- Hanya front-end; data contoh dan perubahan selama sesi tidak dikirim ke server.
- Login dan pembatasan data antarkampung belum tersambung ke backend.
- Gambar QR adalah ilustrasi visual dan belum dapat dipindai. Integrasi scanner, pembayaran, database online, sinkronisasi, serta printer thermal belum tersedia.
- Halaman ini tidak mengirim tiket atau notifikasi kepada pengunjung.

Buka `index.html` melalui GitHub Pages untuk mencoba simulasi.
