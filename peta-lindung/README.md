# RuangRimba — Peta Hutan Lindung

Prototype web responsif untuk menunjukkan alur publik melihat batas kawasan hutan lindung dan pemeriksaan posisi di dalam/di luar kawasan.

## Tampilan demo

- Peta ilustrasi dengan batas kawasan, titik posisi, legenda, dan kontrol lapisan.
- Kartu hasil pemeriksaan lokasi serta ringkasan sumber ArcGIS.
- Layout responsif untuk ponsel dan desktop.

## Batasan

Ini hanya simulasi front-end. Peta dan koordinat adalah ilustrasi; kontrol lokasi tidak membaca GPS perangkat. Layer ArcGIS, pembaruan batas, autentikasi, basis data, sinkronisasi real-time, dan akses multi-pengguna belum tersambung. Data resmi/layanan ArcGIS perlu disediakan dan ditinjau sebelum integrasi.
