# ArunaPay — pratinjau layanan PPOB

Demo antarmuka responsif untuk layanan pulsa dan PPOB. Memuat dashboard agen, kategori layanan (pulsa, paket data, token listrik, e-wallet, tagihan, voucher), saldo/rekap contoh, transaksi terbaru, akses cepat agen, dan dialog alur transaksi contoh.

## Batas demo

- Front-end statis untuk pratinjau; saldo, transaksi, status dan angka adalah data sintetis.
- Dialog hanya menampilkan konfirmasi simulasi lokal. Tidak ada backend, autentikasi, API operator, transaksi, pembayaran, atau penyimpanan data.
- Nama/identitas demo bersifat generik dan bukan branding pelanggan.
