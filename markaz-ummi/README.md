# RuangUmmi — prototipe administrasi lembaga

Demo front-end untuk meninjau alur ringkasan pusat, beberapa lembaga, koordinator/guru/orang tua, kelompok siswa, perpindahan kelompok, jurnal, penilaian, kalender pendidikan, program semester, dan rekap contoh. Pembaruan pratinjau menambahkan katalog lima kategori format (rapor, kolom bendahara, praktik ibadah mingguan, penilaian Taksonomi Bloom pra-TK bulanan, dan karya Rabu Ceria mingguan), antrean tinjauan admin, serta satu halaman profil umum lintas lembaga.

## Cara mencoba

Buka `index.html` melalui GitHub Pages atau server statis, lalu gunakan navigasi di sisi kiri. Pada halaman **Siswa & kelompok**, coba **Tambah siswa** untuk mencatat lembaga, kelompok awal, dan tahun ajaran masuk; gunakan **Pindahkan** untuk mengganti kelompok dan melihat kelompok lama tetap tercatat sebagai riwayat. Pilihan peran di kanan atas hanya mengganti label pratinjau. Buka **Format penilaian** untuk melihat lima kategori dan alur pembaruan menunggu tinjauan admin. Buka **Profil publik** untuk melihat satu halaman ringkasan semua lembaga; isinya hanya informasi umum dan kontak placeholder, tanpa rincian siswa.

## Batasan demo

Semua nama dan angka adalah data sintetis. Ini hanya prototipe UI; login, hak akses nyata, pemisahan data lembaga, database, penyimpanan jurnal/lampiran, sinkronisasi, proses persetujuan yang sesungguhnya, dan ekspor dari data produksi belum tersambung. Kolom rinci pada lima format masih contoh umum karena formulir asli belum tersedia. Pendataan tahun masuk dan perpindahan kelompok hanya simulasi front-end; perubahan contoh tersimpan sementara selama halaman terbuka. Tampilan bukan aplikasi produksi.
