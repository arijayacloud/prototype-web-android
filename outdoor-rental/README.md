# Rimba Gear — Sewa Perlengkapan Outdoor

Prototipe front-end untuk katalog dan permintaan sewa perlengkapan outdoor.

## Yang dapat dicoba
- Cari dan filter perlengkapan menurut kategori.
- Tambahkan barang ke permintaan sewa dan isi detail booking serta rentang tanggal.
- Terapkan kode kupon contoh dan lihat subtotal simulasi.
- Buka panel admin untuk ringkasan, tabel booking, status konfirmasi manual, stok contoh, dan ekspor CSV.

## Batas prototipe
Semua nama barang, harga, stok, booking, dan laporan adalah data contoh. Interaksi hanya berjalan di browser dan tidak disimpan ke server. Pembayaran, akun, inventori lintas perangkat, ketersediaan tanggal nyata, notifikasi, dan konfirmasi produksi belum terhubung.

Buka `index.html` atau halaman GitHub Pages setelah deployment terverifikasi.
