# Buku Kas Kantor — Pencatatan Kas & Barang

Aplikasi pencatatan kas kantor (uang dan barang) dengan saldo berjalan, jurnal transaksi, dan cetak laporan PDF A4 / struk Thermal 58mm. Data tersimpan di `localStorage`.

## Fitur
- **Posisi kas saat ini**: saldo, uang masuk, pengeluaran, total entri.
- **Tambah transaksi**: kategori *Uang* (Uang Masuk, Pengeluaran) atau *Barang* (Pembelian mengurangi kas, Pengembalian menambah kas, Kirim Barang tidak memengaruhi kas). Qty × nilai dihitung otomatis dengan keterangan efek ke saldo.
- **Jurnal kas & barang**: pencarian, tab Semua/Barang/Uang, filter periode, saldo berjalan per baris, ubah/hapus, Export CSV.
- **Rekap barang**: dibeli, dikembalikan, dikirim, sisa stok, estimasi nilai stok, dan daftar pengiriman.
- **Laporan**: PDF / A4 (lembar kas & barang, daftar pengiriman, tanda tangan) dan Thermal 58mm.
- **Setelan**: nama pengguna, nama kantor, saldo awal, cadangan/pulihkan JSON, data contoh.
