# RuangDesa — prototipe administrasi kependudukan

Demo front-end untuk membahas cakupan aplikasi administrasi desa. Halaman mencontohkan ringkasan statistik, daftar penduduk dan keluarga, pengajuan surat, catatan mutasi, pembagian peran, rekap wilayah, pencarian, serta unduhan CSV contoh.

## Batas demo

- Seluruh isi memakai data ilustrasi; jangan memasukkan data penduduk nyata.
- Form dan perubahan data hanya tersimpan sementara di halaman browser dan hilang saat halaman dimuat ulang.
- Login, hak akses server, database, sinkronisasi multiuser, backup/pemulihan, notifikasi, peta lokasi, integrasi bantuan sosial, pengajuan resmi, dan penyimpanan dokumen belum tersambung ke backend atau layanan eksternal.
- CSV hanya mengekspor data contoh di halaman ini. Peta merupakan ilustrasi, bukan koordinat warga.

Buka `index.html` di browser untuk mencoba navigasi, pencarian, form contoh, filter surat, dan ekspor CSV.
