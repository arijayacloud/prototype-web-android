# PO Baju — Platform Jualan Baju (Prototype)

Fitur utama:
- **Login / Daftar** — akun pelanggan & admin
- **Produk** — katalog baju (model, warna, ukuran, stok)
- **Keranjang** — pilih ukuran & warna, tambah kuantitas, hapus
- **Checkout** — masukkan alamat (dapat disimpan), pilih metode pembayaran
- **Pembayaran Online** — multi-metode (transfer bank, e-wallet, kartu kredit)
- **Ongkir Otomatis** — tarif flat per order (DAPAT DIDESAIN ULANG)
- **Notifikasi** — realtime pesanan masuk, status update
- **Dashboard Admin** — kelola pesanan, maju status, notifikasi

Simpan di: `/home/ubuntu/github2/prototype-web-android/po-baju/index.html`

Demo: https://arijayacloud.github.io/prototype-web-android/po-baju/

Catatan:
- Data disimpan di `localStorage` — refresh browser hapus semua sesi
- Fitur chat WA admin bisa diganti dengan modal konten admin
- Notifikasi realtime lebih sederhana, sesuai untuk demo
- Tidak ada backend — murni frontend prototype
- Desain cukup minimal, bisa dikembangkan lagi
