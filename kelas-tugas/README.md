# KelasKita — Ruang Tugas

Prototipe front-end untuk ruang kelas digital, berdasarkan kebutuhan pelanggan akan web untuk guru membagikan dan memantau tugas, sementara siswa mengumpulkan jawaban melalui unggahan foto atau dokumen. Tugas dikelompokkan berdasarkan kelas dan mata pelajaran.

## Alur demo

- Beralih antara pratinjau peran **Guru** dan **Siswa**.
- Guru melihat ringkasan kelas, membuat tugas dengan kelas, mata pelajaran, tenggat, instruksi, dan jenis lampiran.
- Guru memantau progres pengumpulan dan daftar kiriman contoh.
- Siswa memilih tugas, memilih berkas foto atau dokumen, lalu mencoba alur pengumpulan.
- Halaman kelas menampilkan folder kelas dan mata pelajaran.

## Batasan demo

Semua nama, aktivitas, jumlah, kiriman, dan status merupakan data contoh. Pilihan berkas serta perubahan hanya disimulasikan di browser dan tidak dikirim atau disimpan di server. Login, database, unggahan permanen, notifikasi, dan pengelolaan akun membutuhkan backend.

Folder ini dapat dibuka dari GitHub Pages pada path `/kelas-tugas/`.
