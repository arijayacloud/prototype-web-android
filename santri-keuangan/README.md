# Santri Finance — Prototype

Front-end prototype for a pesantren student-fee and finance administration workflow. It demonstrates year-based student records, fee categories and balances, payment entry, income/expense entry, payment status lookup, and transaction history.

All records are illustrative and stored only in the current browser using localStorage. This is not a production system: it has no server database, account/login controls, backups, multi-user access, or real payment integration. Refreshing the browser on the same device preserves demo entries; another device will not see them.
