# Catatan Hajatan — Buku Tamu Digital

Aplikasi mobile untuk mencatat tamu hajatan (pernikahan, khitan, dll.) beserta sumbangan uang/barang, dengan rekap otomatis dan export laporan. Data tersimpan offline di `localStorage`.

## Layar
1. **Splash Screen** — tampilan awal.
2. **Menu Utama** — data hajat, ringkasan tamu, akses Data Tamu, Rekapitulasi, Laporan, Pengaturan.
3. **Data Tamu** — daftar tamu, cari nama/alamat, filter Semua/Putra/Putri, tambah/ubah/hapus (nominal cepat, barang, hubungan).
4. **Rekapitulasi** — total tamu putra/putri, uang putra/putri, total uang, tamu per hubungan dan per alamat.
5. **Laporan & Export** — Laporan Tamu, Rekapitulasi, Detail Per Kategori, Laporan Harian; format PDF (cetak), Excel (CSV), Gambar (PNG).
6. **Pengaturan** — data hajatan, cadangan/pulihkan JSON, data contoh, hapus semua.
