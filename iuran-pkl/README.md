# KasRapi — Iuran PKL

Prototype responsif untuk alur pencatatan iuran peserta PKL.

## Alur demo

- Daftar peserta, kelompok/kelas, nilai iuran, jumlah dibayar, dan status.
- Pencarian serta filter status pembayaran.
- Form tambah peserta dan tombol catat pembayaran menggunakan data demo pada browser.
- Cetak/simpan laporan melalui fitur cetak browser (termasuk opsi PDF).

## Batasan

Ini prototype web, bukan APK Android final. Nama, kelompok, nominal, dan pembayaran yang disediakan adalah contoh. Perubahan demo tersimpan lokal di browser; belum ada sinkronisasi antarperangkat, akun, server, ataupun database bersama.
